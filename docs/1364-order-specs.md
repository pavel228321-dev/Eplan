## Что это меняет в проекте / на что обратить внимание

1. **Danfoss FC51 снят с производства** — риск для заказа, стоит поднять с
   заказчиком/Aprotec до начала обвязки, а не после.
2. **Размеры шкафов разошлись со звонком** — использовать `1000×800×300`
   (ШРП-1/ШРП-2) и `1800×1000×400` (ШУ) как источник истины.
3. **Каждый ПЧ имеет фиксированный "комплект" защиты**: `GV3P32` (автомат) +
   `GVAN11` (доп. контакты, диагностика по ПО) — это и есть состав "обвязки ПЧ"
   с точки зрения силовой части, до самого шкафа НКУ.
4. **45 реле `RIF-0-RPT-24DC/21`** — самая массовая позиция НКУ, вероятно,
   промежуточные реле на каждый дискретный выход или группу выходов — стоит
   уточнить логику применения перед проектированием силовой части.
5. Деление "3+2" по шкафам периферии подтверждено уже 3 независимыми источниками:
   запись звонка, спецификация клеммников (панели вводов), спецификация
   пневмоостровов (3+2 острова).
